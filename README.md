# 록맨 X 서바이버즈 (Rockman X Survivors)

**한국어** | [English](README.en.md)

록맨 X의 엑스가 되어 쏟아지는 적 사이에서 **30분 동안 살아남는** 뱀서류(생존 액션) 팬 게임입니다.
X4 · X5 · X6의 특수 무기와 아머를 모아 나만의 빌드를 완성해 보세요.

> ⚠️ **비공식 팬 게임 · 비영리 배포**
> 록맨 X(Mega Man X)의 캐릭터, 그림, 음악 등 모든 권리는 **CAPCOM**에 있습니다.
> 이 게임은 팬이 비영리 목적으로 만든 2차 창작물이며 CAPCOM과 관계가 없습니다. 판매·유료 배포를 금지합니다.

## ▶ 실행 방법

1. 받은 zip 파일을 **압축 해제**합니다. (압축 파일 안에서 바로 실행하면 제대로 동작하지 않습니다)
2. 압축을 푼 폴더에서 **`RockmanXSurvivors.exe`** 를 실행합니다.
3. 처음 실행할 때 **"Windows의 PC 보호"** 창이 뜰 수 있습니다.
   개인이 만든 서명되지 않은 프로그램이라 나오는 안내이니, **추가 정보 → 실행**을 눌러 주세요.

### 언어
- PC 언어가 한국어면 한국어로, 아니면 영어로 시작합니다.
- **환경설정**에서 언제든 **한국어 / English**를 바꿀 수 있습니다.

### 권장 환경
| 항목 | 내용 |
|---|---|
| 운영체제 | Windows 10 / 11 (64비트) |
| 입력 | 키보드(마우스 선택) 또는 엑스박스 호환 게임패드 |
| 설치 | 필요 없음 (압축 해제 후 바로 실행) |

## 📖 게임 안내

### 목표
- **30분 동안 살아남으면 클리어**입니다. 시간이 지날수록 더 강한 적과 강화형 적이 몰려옵니다.
- 적을 쓰러뜨리면 나오는 **에너지 결정**을 모아 레벨업하고, 카드 3장 중 하나를 골라 강해집니다.

### 성장 요소
| 요소 | 설명 |
|---|---|
| 버스터 성장 | 1발 → 2연발 → 3연발 → 세미 차지 → 풀 차지 |
| 특수 무기 9종 | X4 · X5 · X6 시리즈 무기. 5레벨이 되면 **진화**합니다 |
| 시리즈 시너지 | 같은 시리즈 무기 3종을 모으면 공격력 · 연사력 · 이동 속도 증가 |
| 아머 | 가장 먼저 시너지를 완성한 시리즈의 아머 파츠 4개를 모으면 **포스 · 팔콘 · 블레이드 아머** 완성. 받는 피해가 줄고 **기가어택**을 쓸 수 있습니다 |
| 새로고침 | 레벨업 카드가 마음에 들지 않으면 다시 뽑을 수 있습니다(횟수 제한) |

### 레플리로이드 구출
- 플레이 중 화면 밖에 **"HELP!"** 를 외치는 레플리로이드가 나타납니다. 화면 가장자리 화살표를 따라가 닿으면 구출!
- 외형마다 보상이 다릅니다.

| 외형 | 보상 |
|---|---|
| 초록 | 체력 회복 |
| 핑크 | 체력 대량 회복 |
| 금색 | 맵의 경험치 전부 흡수 |
| 보라 | 새로고침 +1 |

### 라이트 박사 연구소 (영구 강화)
- 판이 끝나면 생존 시간 · 처치 수 · 레벨에 따라 **메탈**을 받습니다. (레벨업 카드 *메탈 회수* 로도 모을 수 있습니다)
- 메인 메뉴의 **연구소**에서 메탈로 공격력, 하트 탱크(최대 체력), 서브 탱크 등을 영구히 강화할 수 있습니다.
- 강화는 언제든 **전부 초기화**해서 메탈을 돌려받을 수 있습니다.

## 💾 세이브 데이터

진행 상황(메탈, 연구소 강화, 최고 기록, 환경설정, 언어)은 자동으로 저장됩니다.

```
C:\Users\(사용자 이름)\AppData\LocalLow\RXSFanGame\Rockman X Survivors\save.json
```

- 새 버전으로 바꿔도 이 파일은 그대로 유지됩니다.
- 처음부터 다시 하고 싶다면 이 파일을 지우면 됩니다.

### 삭제 방법
게임 폴더를 지우면 됩니다. 세이브까지 지우려면 위 경로의 `Rockman X Survivors` 폴더도 함께 지워 주세요.

## ❓ 자주 묻는 질문

**Q. 실행했는데 바로 꺼져요 / 검은 화면이에요.**
압축을 완전히 푼 뒤 실행했는지 확인해 주세요. 폴더 안의 다른 파일(`…_Data` 폴더 등)이 함께 있어야 실행됩니다.

**Q. 백신이 실행을 막아요.**
서명되지 않은 개인 제작 프로그램이라 일부 백신이 의심 파일로 표시할 수 있습니다. 이 저장소의 [릴리즈 페이지](../../releases)에서 받은 파일만 사용해 주세요.

**Q. 창 모드 / 전체 화면을 바꾸고 싶어요.**
메인 메뉴 또는 일시정지 메뉴의 **환경설정 → 화면 모드**에서 바꿀 수 있습니다.

**Q. 배경음악을 바꿀 수 있나요?**
**환경설정 → 음표 버튼(BGM)** 에서 메인 화면 곡과 게임 곡을 고를 수 있습니다.
